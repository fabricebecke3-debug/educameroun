Mathématiques — 3eme

1. Les identités remarquables

Identités remarquables (a et b sont des nombres ou des expressions) :
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²

On les utilise pour développer une expression ou calculer rapidement un carré.

Exemple : pour calculer 99², on écrit 99 = 100 − 1 : (100 − 1)² = 10 000 − 200 + 1 = 9 801.

Exemple de développement : (x + 3)² = x² + 6x + 9.

💡 Le double produit 2ab est souvent oublié : vérifie-le toujours.

Exercices d'application

Q1. Développe (x + 2)².

Correction : x² + 4x + 4.

Q2. Calcule 98² en utilisant (100 − 2)².

Correction : 10 000 − 400 + 4 = 9 604.

Q3. Développe (y + 5)(y − 5).

Correction : y² − 25.

QCM

1. (a + b)² est égal à :
A) a² + b² · B) a² + 2ab + b² · C) a² + ab + b² · D) 2a + 2b
Réponse : B — C'est l'identité du carré d'une somme.

2. (a + b)(a − b) est égal à :
A) a² − b² · B) a² + b² · C) 2ab · D) a − b
Réponse : A — C'est la différence de deux carrés.

3. (x − 1)² est égal à :
A) x² − 1 · B) x² − 2x + 1 · C) x² + 1 · D) x² − 2x − 1
Réponse : B — On applique (a − b)² avec b = 1.

4. Pour calculer 101², on écrit :
A) (100 + 1)² · B) (10 + 1)² · C) 101 × 1 · D) 100² + 1
Réponse : A — (100 + 1)² = 10 201.

5. (2x)² est égal à :
A) 2x² · B) 4x² · C) 4x · D) x²
Réponse : B — (2x)² = 4x².

2. Les équations du premier degré

Équation : égalité contenant une inconnue (souvent x). Résoudre l'équation, c'est trouver la valeur de x qui rend l'égalité vraie.

Méthode : 1) développer les parenthèses ; 2) regrouper les x d'un côté et les nombres de l'autre ; 3) diviser par le coefficient de x.

Exemple : 2x + 3 = 11 → 2x = 8 → x = 4.
Autre exemple : 5(x − 1) = x + 7 → 5x − 5 = x + 7 → 4x = 12 → x = 3.
Contexte camerounais : un commerçant vend x sacs de riz à 2 000 F le sac et ajoute 500 F de frais. Il reçoit 9 500 F : 2 000x + 500 = 9 500, donc x = 4,5 ; il faut vérifier si la situation est possible.
💡 Vérifie toujours ta solution : remplace x par la valeur trouvée dans l'équation de départ.

Exercices d'application

Q1. Résous 4x − 5 = 7.

Correction : 4x = 12, donc x = 3.

Q2. Résous 3(x + 2) = 18.

Correction : 3x + 6 = 18, donc 3x = 12 et x = 4.

Q3. Résous x/2 + 1 = 5.

Correction : x/2 = 4, donc x = 8.

QCM

1. La solution de 2x = 10 est :
A) 2 · B) 5 · C) 20 · D) 8
Réponse : B — x = 10 ÷ 2 = 5.

2. La solution de x + 4 = 9 est :
A) 13 · B) 5 · C) 4 · D) 36
Réponse : B — x = 9 − 4 = 5.

3. La solution de 3x − 6 = 0 est :
A) −2 · B) 3 · C) 2 · D) 6
Réponse : C — 3x = 6, donc x = 2.

4. Résous 2(x − 1) = 8 :
A) 3 · B) 5 · C) 4 · D) 6
Réponse : B — 2x − 2 = 8, 2x = 10, x = 5.

5. Pour résoudre une équation, la première étape est souvent :
A) diviser par 0 · B) développer les parenthèses · C) ajouter une inconnue · D) arrondir
Réponse : B — On développe avant de regrouper les termes.
