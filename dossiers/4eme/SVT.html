SVT — 4eme

1. La reproduction des plantes à fleurs

Reproduction sexuée : création d'un nouvel être vivant à partir de la rencontre de deux cellules sexuelles (gamètes) : le pollen et l'ovule.

Les parties de la fleur : les étamines produisent le pollen ; le pistil contient les ovules.

La pollinisation : le transport du pollen vers le pistil, par le vent, les insectes ou les oiseaux.

La fécondation : la rencontre du pollen et de l'ovule. L'ovule devient une graine, et l'ovaire devient le fruit.

Exemple camerounais : les abeilles visitent les fleurs de papayer ; en transportant le pollen, elles permettent la formation des fruits.
💡 Retiens : pollen → pistil (pollinisation), puis ovule → graine et ovaire → fruit (fécondation).

Exercices d'application

Q1. Quelle partie de la fleur produit le pollen ?

Correction : Les étamines.

Q2. Qu'est-ce que la pollinisation ?

Correction : Le transport du pollen vers le pistil.

Q3. Que devient l'ovule après fécondation ?

Correction : Il devient la graine.

QCM

1. Le pistil contient :
A) le pollen · B) les ovules · C) les pétales seulement · D) les feuilles
Réponse : B — Les ovules se trouvent dans le pistil.

2. La pollinisation est réalisée par :
A) la pluie seule · B) le vent ou les insectes · C) les racines · D) le sol
Réponse : B — Le vent et les insectes transportent le pollen.

3. L'ovaire devient :
A) la graine · B) le fruit · C) la feuille · D) la racine
Réponse : B — Après fécondation, l'ovaire devient le fruit.

4. La reproduction sexuée repose sur :
A) une seule cellule · B) la rencontre de deux gamètes · C) la division de la tige · D) le bouturage seul
Réponse : B — Elle exige la rencontre de deux gamètes.

5. Les étamines sont :
A) les parties qui produisent le pollen · B) les racines · C) les graines · D) les fruits
Réponse : A — Elles fabriquent le pollen.
