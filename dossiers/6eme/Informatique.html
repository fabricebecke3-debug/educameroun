Informatique — 6eme

1. L'ordinateur et ses parties

Ordinateur : machine qui reçoit des informations (entrées), les traite, puis fournit un résultat (sorties).

Les périphériques d'entrée : clavier, souris, scanner, micro. Ils envoient des informations à l'ordinateur.

Les périphériques de sortie : écran, imprimante, haut-parleurs. Ils présentent le résultat.

L'unité centrale : c'est le « cerveau » qui traite les données, avec le processeur et la mémoire.

Exemple : pour imprimer un devoir, je tape le texte au clavier (entrée), l'ordinateur le traite, puis l'imprimante le reproduit sur papier (sortie).
💡 Retiens : entrée = ce que je donne à l'ordinateur ; sortie = ce qu'il me rend.

Exercices d'application

Q1. Donne deux périphériques d'entrée.

Correction : Clavier et souris (ou scanner, micro).

Q2. Donne deux périphériques de sortie.

Correction : Écran et imprimante (ou haut-parleurs).

Q3. Quel élément de l'ordinateur traite les données ?

Correction : L'unité centrale, avec son processeur.

QCM

1. Le clavier est un périphérique :
A) de sortie · B) d'entrée · C) de stockage uniquement · D) inutile
Réponse : B — Il permet d'envoyer des informations à l'ordinateur.

2. L'écran est un périphérique :
A) d'entrée · B) de sortie · C) de traitement · D) de connexion
Réponse : B — Il affiche le résultat.

3. Le « cerveau » de l'ordinateur est :
A) la souris · B) l'imprimante · C) l'unité centrale · D) le câble
Réponse : C — L'unité centrale traite les données.

4. L'imprimante est un périphérique :
A) d'entrée · B) de sortie · C) de saisie · D) de calcul
Réponse : B — Elle produit un résultat sur papier.

5. Le scanner est un périphérique :
A) de sortie · B) d'entrée · C) de traitement · D) d'affichage
Réponse : B — Il envoie une image à l'ordinateur.

2. Fichiers et dossiers

Fichier : ensemble d'informations enregistrées sous un nom (texte, image, musique). Dossier : espace qui range des fichiers et d'autres dossiers, comme une armoire.

Créer un dossier : clic droit → Nouveau → Dossier, puis on lui donne un nom clair (ex : « Maths 6ème »).

Copier, déplacer, supprimer : on copie avec Ctrl+C puis on colle avec Ctrl+V. Un fichier supprimé va dans la Corbeille, d'où on peut le restaurer.

Bien nommer : un nom précis (ex : « Devoir_SVT_2026 ») évite de perdre un fichier.

Exemple : un élève range ses cours dans un dossier « Cours » contenant les sous-dossiers « Français », « Maths » et « SVT ».
💡 Enregistre tes travaux régulièrement et range-les dès le début : tu gagneras beaucoup de temps.

Exercices d'application

Q1. Quelle différence y a-t-il entre un fichier et un dossier ?

Correction : Un fichier contient des informations ; un dossier range des fichiers et d'autres dossiers.

Q2. Quels raccourcis permettent de copier puis coller ?

Correction : Ctrl+C pour copier, Ctrl+V pour coller.

Q3. Où va un fichier supprimé par erreur ?

Correction : Dans la Corbeille, d'où on peut le restaurer.

QCM

1. Un dossier sert à :
A) afficher une image · B) ranger des fichiers · C) imprimer · D) se connecter à Internet
Réponse : B — Un dossier range des fichiers.

2. Le raccourci pour coller est :
A) Ctrl+C · B) Ctrl+V · C) Ctrl+Z · D) Ctrl+P
Réponse : B — Ctrl+V colle.

3. Un fichier supprimé se trouve d'abord dans :
A) le dossier Images · B) la Corbeille · C) l'imprimante · D) le clavier
Réponse : B — La Corbeille permet de le restaurer.

4. Quel nom de fichier est le plus clair ?
A) doc1 · B) xyz · C) Devoir_SVT_2026 · D) fichier final final
Réponse : C — Un nom précis facilite le retrouver.

5. Pour créer un dossier, on fait :
A) un clic gauche sur l'écran · B) un clic droit → Nouveau → Dossier · C) un double clic sur la souris seule · D) on éteint l'ordinateur
Réponse : B — Le menu clic droit permet de créer un dossier.
