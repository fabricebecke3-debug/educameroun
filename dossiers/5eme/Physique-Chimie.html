Physique-Chimie — 5eme

1. Les solutions : soluté et solvant

Solution : mélange homogène obtenu quand une substance (le soluté) se dissout dans un liquide (le solvant).

Exemple : du sel (soluté) dissous dans de l'eau (solvant) donne de l'eau salée.

Solubilité : capacité d'un soluté à se dissoudre. Le sucre se dissout bien dans l'eau chaude, mieux que dans l'eau froide.

Exemple camerounais : le jus de bissap est une solution : les arômes et les colorants de la fleur d'hibiscus se dissolvent dans l'eau, et le liquide reste homogène.
💡 Une solution est homogène : on ne voit pas les particules du soluté, même si elles sont bien présentes.

Exercices d'application

Q1. Dans de l'eau sucrée, quel est le soluté ?

Correction : Le sucre.

Q2. Dans l'eau salée, quel est le solvant ?

Correction : L'eau.

Q3. Une solution est-elle un mélange homogène ou hétérogène ?

Correction : Un mélange homogène.

QCM

1. Le soluté est :
A) le liquide qui dissout · B) la substance qui se dissout · C) le récipient · D) le gaz
Réponse : B — Le soluté se dissout dans le solvant.

2. Le solvant est généralement :
A) le sel · B) le liquide qui dissout · C) le sucre · D) le fer
Réponse : B — C'est le liquide dans lequel on dissout.

3. Un mélange homogène a :
A) plusieurs aspects visibles · B) un seul aspect · C) des couches séparées · D) des solides visibles
Réponse : B — Une solution a un aspect uniforme.

4. Le sucre se dissout mieux dans :
A) l'eau froide · B) l'eau chaude · C) l'huile · D) l'air
Réponse : B — La chaleur augmente la solubilité du sucre.

5. Le bissap, une fois préparé, est :
A) un corps pur · B) une solution · C) un gaz · D) un solide
Réponse : B — C'est une solution où les arômes sont dissous.
